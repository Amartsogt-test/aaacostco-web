# 5 Шинэ боломжийн хэрэгжүүлэлтийн төлөвлөгөө (Implementation Plan)

Хэрэглэгчийн болон Админы туршлагыг сайжруулах зорилгоор доорх 5 том өөрчлөлтийг хийхээр төлөвлөлөө.

## Proposed Changes

---

### 1. Сагсны анимаци (Cart Animation)
Хэрэглэгч бараа сагслах үед сагсны дүрс (icon) томорч жижигрэн (bounce) анхаарал татах анимаци нэмнэ.

#### [MODIFY] `src/components/Header.jsx` (эсвэл `SearchFilterBar.jsx`)
- Сагсны тоог харуулдаг хэсэгт CSS `animate-bounce` эсвэл тусгай keyframe анимаци нэмнэ.
- Zustand-ийн `cart` state өөрчлөгдөх бүрт анимацийг trigger хийнэ.

---

### 2. Барааны зураг томруулагч (Image Zoom/Lightbox)
Барааны дэлгэрэнгүй хуудсан дээр зураг дээр дарах эсвэл хулганаа аваачихад зураг томорч харагддаг болгоно.

#### [MODIFY] `src/pages/ProductDetail.jsx`
- Барааны үндсэн зургийг харуулж буй хэсэгт `onClick` event нэмж, дэлгэц дүүрэн (FullScreen Modal) байдлаар харуулдаг шинэ State (жишээ нь `isFullscreen`) үүсгэнэ.
- Эсвэл хулганы хөдөлгөөнөөр зураг дотроо zoom хийгддэг (Magnifier) нөлөөг CSS `transform` ашиглан хийнэ. (Эхний ээлжинд Modal хэлбэрээр хийх нь илүү гар утсанд ээлтэй).

---

### 3. Админ статистик (Dashboard Statistics)
Админы нүүр хуудсанд нийт бараа, хямдралтай барааны тоо зэргийг харуулсан гоёмсог картууд нэмнэ.

#### [MODIFY] `src/pages/AdminDashboard.jsx`
- Хуудасны дээд хэсэгт эсвэл тусгай `Stats` хэсэгт нийт бараа, идэвхтэй болон идэвхгүй барааны тоо, нийт категорийн тоо зэргийг `products` array-ээс тооцоолон харуулсан картуудыг нэмнэ.
- (Хэрэв Orders дата байгаа бол нийт захиалгыг харуулна).

---

### 4. Зочин захиалга шалгах (Guest Order Tracking)
Бүртгэлгүй хэрэглэгч утасны дугаар болон захиалгын ID ашиглан захиалгаа шалгах боломж.

#### [NEW] `src/pages/GuestOrderTracking.jsx`
- Шинээр хуудас үүсгэнэ. 2 ширхэг input (Утас, Захиалгын ID) байна.
- Firebase-ээс тухайн захиалгыг хайж олоод төлөвийг нь (Pending, Shipped, Delivered) харуулна.
#### [MODIFY] `src/App.jsx`
- Шинэ Route `/track-order` нэмнэ.
#### [MODIFY] `src/components/Header.jsx`
- Цэсэнд "Захиалга шалгах" холбоосыг нэмнэ.

---

### 5. Ухаалаг хайлт (Autocomplete Dropdown)
Хайлт хийх үед илэрцүүдийг шууд хайлтын хэсгийн доор унаж ирдэг (dropdown) байдлаар харуулна.

#### [MODIFY] `src/components/SearchFilterBar.jsx`
- Хайлтын `input`-ийн доор `absolute` байрлалтай `div` үүсгэж, `searchTerm` өөрчлөгдөх үед `filteredProducts`-ийн эхний 5 үр дүнг зурагтай нь харуулна.
- Хэрэглэгч үр дүнгээс сонгоход шууд тухайн барааны дэлгэрэнгүй хуудас руу шилждэг болгоно.

---

## Verification Plan
1. Барааг сагсанд нэмэх үед Сагсны icon хөдөлж байгааг харах.
2. Барааны зураг дээр дарахад дэлгэц дүүрэн гарч байгаа эсэхийг шалгах.
3. Админ самбар луу орж статистик картууд зөв ажиллаж байгааг баталгаажуулах.
4. Зочин хэрэглэгчийн утасны дугаар болон ID-аар захиалга хайж олох туршилт хийх.
5. Хайлтын цонхонд үсэг бичих үед drop-down илэрц гарч байгааг шалгах.

> [!NOTE]
> Эдгээр өөрчлөлтүүд нь системийн ажиллагаанд томоохон нөлөө үзүүлэхгүй бөгөөд зөвхөн хэрэглэгчийн туршлагыг сайжруулахад чиглэсэн болно. Төлөвлөгөөгөө баталгаажуулмагц хэрэгжүүлэлтээ эхлэхэд бэлэн байна.
